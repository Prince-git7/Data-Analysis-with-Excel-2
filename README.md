# 🌍 Environment Temperature Change — Excel Data Analysis Project

This project analyzes global temperature change trends using an Excel-based dataset containing country-wise and month-wise temperature variations. The dashboard provides insights into long-term climate patterns using data cleaning, processing, and interactive visualizations.

# 📊 Dataset Columns

The dataset contains the following fields:

Country Code – Unique code for each country

Country – Name of the country

Months Code – Numeric code for the month

Months – Name of the month

Element Code – Code representing temperature measurement

Element – Temperature-related element

Unit – Measurement unit

Year – Year of observation

Temperature Change – Recorded temperature change value

# 🛠️ Project Workflow
1. Data Cleaning

Removed blank rows and duplicate data

2. Data Processing

3. Data Analysis

Identified long-term temperature change trends

Compared countries, months, and elements

Highlighted unusual temperature patterns
